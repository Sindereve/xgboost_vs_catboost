# Эксперимент по сравнению обработки категориальных признаков в XGBoost и CatBoost на датасетах из Kaggle.

## Цель

Сравнить эффективность нового категориального ре-кодера в XGBoost с нативной обработкой категорий в CatBoost на различных типах данных.

## Модели для сравнения 

- CatBoost - с нативной обработкой категорий
- XGBoost Manual - с ручным кодированием (OneHot + Ordinal)
- XGBoost Auto - с автоматическим ре-кодером
